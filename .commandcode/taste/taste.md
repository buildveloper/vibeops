# Taste Profile

## Design & UX

- Separates UX from UI: judges product quality primarily by navigation clarity and how quickly a first-time, non-technical user understands what to do, not by visual polish. When asking for a UX rework, expects the existing visual design to be preserved rather than redesigned. Confidence: 0.8
- Uses a "would a $100M company built by a top-tier agency ship this?" bar as the target quality level for product experience — expects layman-friendly language, obvious next steps, and no dead ends. Confidence: 0.7
- Values aggressive simplification of information architecture: fewer destinations, one clear name per concept, and plain English over internal/literary product vocabulary. Confidence: 0.6
